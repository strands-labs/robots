### Fixed

- **transforms**: the re-validation gate no longer accuses a verdict that copied the episode before reading it of consulting no pixels. `DatasetTransform.transform` may report a run as gated only if the verdict it ran read an `observation.images.*` column, and it answered that by wrapping the source episode in a probe that recorded six of `dict`'s twelve value-bearing read paths. A verdict spelling its read as `dict(episode)`, `{**episode}`, `episode.copy()` or `episode | {}` - the defensive copy a caller makes before touching a mapping it was handed - or reaching a column through `pop` / `popitem` / `setdefault`, therefore received every pixel value and was recorded as having read none, so the run reported `revalidated=False` with a message stating the verdict "cannot flip and the output was NOT gated" beside `episodes_discarded=1` on that same gate. Recording now covers every `dict` member that can hand a stored value to a caller, on the rule the class already stated: a bulk read records every key, a keyed read records its key, and a read that reaches no value (`keys()`, iterating keys, `in`, `len()`) records nothing, so a genuinely pixel-blind verdict is still reported as ungated. Nothing about which episodes are generated, discarded or written changes.
