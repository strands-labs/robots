### Fixed

- **docs/device-connect**: the environment reference documented `REACHY_DAEMON_TOKEN` but neither of the two variables that secure the link it travels on, so the only knob that encrypts the Reachy Mini daemon channel - `REACHY_DAEMON_TLS` - appeared nowhere in the docs. An operator who followed the page set the token and got `Bearer <token>` over `http://` and `ws://`: authenticated, and readable by anyone on the segment, which is exactly the posture the code's own docstring warns can be sniffed or replayed. All three daemon-link variables are now documented together under transport security, with their accepted spellings and the plaintext default stated, and a new guard grades the page against the environment surface the package actually reads so a variable added later is documented on arrival.
