### Fixed
- **mesh/audit**: `read_audit_log` now reads past bytes that are not valid UTF-8 instead of aborting on them. Each log file was decoded strictly under an `except OSError` handler, and a comment claimed a `UnicodeDecodeError` raised inside the with-block landed there - it does not, because `UnicodeDecodeError` is a `ValueError`. One byte from a torn write, failing media, or forged content in a rotated copy therefore discarded the records already collected from earlier rotated copies and raised out of `verify_audit_integrity`, so an attacker unable to forge an HMAC could silence the whole tamper report by writing a single byte. Undecodable bytes are now replaced, which confines the damage to its own line: surrounding records survive, later rotated copies are still walked, and the damaged line either falls to the existing malformed-JSON skip or, if it still parses, is reported as `bad_signature`. A DEBUG breadcrumb names the file, so the substitution is never silent - every record this module writes is ASCII, so the replacement character can only come from bytes it did not write.
