### Fixed

- **robot**: `Robot(mode="real")` now accounts for every parameter it is given. `data_config` is forwarded to `strands_robots.hardware_robot.Robot`, which declares it and carries it into the `policy_config` a policy is built with - it was dropped between the two, so a multi-camera schema named at the factory selected the policy's default embodiment instead. `urdf_path`, `position`, `orientation` and `keyframe` describe a pose in a simulated world and cannot be forwarded to hardware, so they are reported at debug level the way `backend` already was, rather than discarded in silence. Supply is read by `is not None`, so a valid `keyframe=0` is reported too. Each parameter now states its `mode="real"` scope in its own docstring entry and in the factory reference table.
