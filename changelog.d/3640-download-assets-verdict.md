### Fixed: `download_assets` no longer reports success for a robot it did not fetch. A `robots=` name the registry does not list, or a clone that failed, came back as `status="success"` with `Downloaded: 0, Skipped: 0, Failed: 0`, so a typo read as a completed download. `download_robots` now carries the unknown names in its result as `unknown_names`, and the tool returns `status="error"` naming them, or when any download failed, with a pointer to `action="list"` for the names the registry knows.
