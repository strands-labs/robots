### Fixed

- **simulation/mujoco**: `randomize()` documented its perturbation as persisting "for the rest of the scene's life" and named no operation that ends it, while the one undo it did name (`recompile the scene`) is not a published action. Every scene mutation rebuilds the compiled model from the scene spec, so `add_object`, `remove_object`, `add_camera`, `remove_camera`, `add_robot`, `remove_robot` and `patch_scene_mjcf` each restore the authored scene - a `randomize()` before one of them is a no-op both calls report as success. The docstring and `docs/simulation/domain-randomization.md` now name the boundary and the ordering it implies; the behaviour is unchanged, since the spec carries the authored values that the lighting and position axes measure their bounded offsets from.
