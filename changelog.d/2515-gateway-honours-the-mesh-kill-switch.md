### Fixed

- **mesh**: `STRANDS_MESH=false` is now honoured by the robot-less gateway peer too. README documents it as "a hard kill switch that also overrides an explicit `mesh=True`", but it was resolved by an inline read inside `init_mesh`, and `robot_mesh`'s gateway is the one `Mesh` built without going through `init_mesh` - so an operator who asked for no mesh still got a real Zenoh session, this process advertised to the fleet as a live `gateway-*` peer, and the nine threads `Mesh.start` spawns, cached until the interpreter exited. The switch now has a single authority (`mesh_disabled_by_env`) consulted before the gateway constructs anything, and the tool's refusal names the variable instead of advising a `Robot()` the same switch would refuse. This also removes a source of cross-test pollution: the suite disables the mesh through that same variable, so a started gateway's health loop had been publishing into unrelated tests.
