### Docs: the fleet suite README shows the runs it documents

`examples/fleet/README.md` described five orchestration examples and a
read-only dashboard in prose alone. It now opens with the clip example 04
records through its own `--gif` flag - the three-phase evacuation on a MuJoCo
corridor world, abort to corridor-distance retreat to lockout, with the
personnel proxy reaching the exit the benchmark scores - and adds two stills
where prose was carrying a picture's load: the one-world/three-vendor scene
example 01 dispatches into, and the dashboard's terminal renderer attached to
a live example 02 run, fleet presence table plus the audit-tail handoff
timeline through to the unroutable request's `handoff_refused`. All three
artifacts come out of the examples' documented commands on a stock checkout;
nothing new to run, nothing narrated that the suite does not already do.
