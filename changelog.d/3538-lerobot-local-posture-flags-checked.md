### Fixed: `lerobot_local` refuses a non-boolean `strict_keys` or `cache_model`. Both flags were stored as given and read by truthiness, so `strict_keys="false"` (a spelling a JSON `policy_config` reaches for) selected the strict posture and the first degraded camera or joint binding raised `strict_keys=True: ...` for a caller who had opted out of exactly that. Each is now checked with the same domain as `pad_short_actions`, naming the parameter and the value it was given; `True`, `False` and NumPy booleans are stored as given.
